# 📊 Dashboard Klasifikasi Tweet Gojek vs Grab

Aplikasi ini merupakan dashboard berbasis **Streamlit** untuk melakukan
klasifikasi dan visualisasi data tweet terkait layanan **Gojek** dan
**Grab** menggunakan Python.

------------------------------------------------------------------------

## 🚀 Menjalankan Aplikasi Secara Lokal

Ikuti langkah-langkah berikut untuk menjalankan aplikasi di komputer
Anda.

### 1️⃣ Clone Repository

``` bash
git clone https://github.com/kuuntakiintee/Dashboard-Klasifikasi-Tweet-Gojek-Grab.git
cd Dashboard-Klasifikasi-Tweet-Gojek-Grab

```

### 2️⃣ (Opsional) Buat Virtual Environment

Disarankan agar dependency tidak bentrok dengan Python lain.

``` bash
python -m venv venv
```

Aktifkan virtual environment:

**Windows**

``` bash
venv\Scripts\activate
```

**macOS / Linux**

``` bash
source venv/bin/activate
```

------------------------------------------------------------------------

### 3️⃣ Install Dependencies

Pastikan file `requirements.txt` tersedia, lalu jalankan:

``` bash
pip install -r requirements.txt
```

------------------------------------------------------------------------

### 4️⃣ Jalankan Aplikasi

``` bash
streamlit run app.py
```

Aplikasi akan otomatis terbuka di browser pada alamat berikut:

    http://localhost:8501
